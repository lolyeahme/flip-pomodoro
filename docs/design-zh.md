# 「flip-pomodoro / 翻页番茄钟」番茄翻页倒计时 — 工程设计方案

## 一、需求规格说明（SRS）

### 功能需求（FR）

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR1 | 任务名称输入（必填），用于专注时显示当前任务 | P0 |
| FR2 | 番茄钟时长可自选（如 5/15/25/45/60 分钟，或自由输入） | P0 |
| FR3 | 循环次数可自选（1–12 轮，默认 4） | P0 |
| FR4 | 专注页面（全屏倒计时界面）上持续显示一条励志句子 | P0 |
| FR5 | 翻页动画倒计时，纯黑底白字 | P0 |
| FR6 | 全屏显示（Fullscreen API + 隐藏状态栏） | P0 |
| FR7 | 番茄钟与目标日期倒数两种模式并存，可切换 | P1 |
| FR8 | 完全离线（无 CDN 外链，资源全部内联或本地） | P0 |
| FR9 | PWA 化，可「添加到主屏幕」 | P1 |
| FR10 | 每轮番茄钟之间插入短休息，休息时长可自行调整 | P0 |
| FR11 | 励志句子来源于成熟的开源库/数据集，不自行生成 | P0 |

### 非功能需求（NFR）

| 类别 | 指标 |
|---|---|
| 性能 | 单文件 < 200KB，加载 < 1s，翻页动画 60fps |
| 兼容 | Chrome/Safari/Edge 及移动端 WebView，iOS ≥ 15 |
| 可维护 | 单一 HTML 文件，原生 JS，无构建步骤 |
| 可用性 | 无需注册、无需联网、零权限申请 |

---

## 二、技术选型决策

| 维度 | 方案 | 理由 |
|---|---|---|
| 翻页动画 | FlipClock.js | 用户指定；成熟、主题化、支持倒计时 |
| 资源加载 | 内联/本地文件，禁用 CDN | 满足 FR8「完全离线」 |
| 番茄逻辑 | 原生 JS 状态机 | 简单、可控、无依赖 |
| 全屏 | Fullscreen API + 兼容 fallback | 跨平台 |
| PWA | manifest + 可选 Service Worker | 满足「添加到主屏幕」 |
| 数据持久化 | localStorage | 保存任务名、时长、轮次 |

**关键决策点（需确认）：** FlipClock.js 依赖 jQuery（老版本）或独立打包。为保持离线与轻量，建议下载其独立 minified 版本与项目文件同目录存放，而非 CDN 引用。

## 三、应用状态机设计

```
[设置页] ──开始──▶ [工作倒计时 25:00]
                      │ 归零
                      ▼
                   [短休息 5:00]  (时长可调)
                      │ 归零
                      ▼
              ── 循环次数 +1 ──▶ 未达目标轮次？──▶ 下一轮(更新励志句)
                      │
                      达目标轮次
                      ▼
                   [完成页] ──▶ 返回设置 / 重新开始

（并行模式：目标日期倒数，可在设置页切换，独立显示距目标日期的翻页倒数）
```

**核心变量：** `taskName`、`pomodoroMinutes`、`cycles`、`currentCycle`、`state`（idle/running/paused/finished）。

## 四、页面/界面结构

1. **设置页**（唯一入口）：
   - 任务名称输入框（必填，空值校验 + 红框提示）
   - 番茄钟时长选择（预设按钮组 + 自定义）
   - 短休息时长选择（可调，默认 5 分钟）
   - 循环次数选择
   - 模式切换：番茄钟 / 目标日期倒数
   - 励志句预览
   - 「开始专注」按钮
2. **专注页**（全屏）：
   - 顶部：任务名称 + 第 N/M 轮
   - 中部：翻页倒计时（黑底白字）
   - 底部：励志句子（持续显示）
   - 手势/按钮：暂停、跳过、放弃
3. **休息页**（全屏）：
   - 翻页倒计时显示休息剩余时间
   - 提示语（如「休息一下」）
4. **完成页**：统计本轮完成情况 + 重新开始

## 五、励志句子数据设计

**最终方案（经用户确认调整）：** 采用鼓舞人心的中文励志格言，内置 56 条经典公版名句与通用励志短句（如“千里之行，始于足下”“天行健，君子以自强不息”“越努力，越幸运”等）。数据直接内嵌于应用，运行时按轮次抽取、去重轮换。**界面不再显示语录来源或开源协议小字。**

> 历史决策：最初要求“使用成熟开源库、不自行生成”，后调整为“鼓舞人心的中文语录”。当前语录均为公版经典格言与通用励志语，无版权归属问题。

## 六、工程文件结构

```
flip-pomodoro/
├── index.html          # 主文件（含全部 CSS/JS 内联）
├── flipclock.min.js    # FlipClock.js 独立包（本地）
├── flipclock.min.css   # FlipClock.js 主题样式（本地，改用黑底白字主题）

└── icon.png            # 应用图标（192×192 / 512×512）
```

> 若需极致单文件，可把 CSS 也内联进 HTML，仅保留 flipclock.min.js 一个外置文件。

## 七、开发流程（Waterfall + 迭代）

1. 环境准备：确认 FlipClock.js 独立包来源（npm 或 GitHub release），下载本地
2. 骨架搭建：HTML 结构 + 黑底白字基础样式 + 全屏按钮
3. 核心逻辑：番茄状态机 + 计时触发 + 循环计数
4. 翻页集成：接入 FlipClock 倒计时，实现黑底白字翻页主题
5. 励志句模块：数组 + 轮换逻辑
6. PWA 化：manifest + 图标 + Service Worker（离线缓存）
7. 自测：桌面 Chrome + 手机浏览器（含横竖屏）
8. 交付：打包成单目录，说明双击/添加主屏用法

## 九、风险与边界

- FlipClock.js 兼容性：新版弃用 jQuery，需确认所用版本 API；若遇障碍，可回退到原生 CSS 翻页（保留备选方案）。
- 全屏限制：iOS Safari 对 Fullscreen API 支持有限，需用「添加到主屏幕」+ 独立窗口兜底。
- 励志句版权：必须选用许可证明确的开源库（如 MIT），并保留出处与许可证声明，不使用来源不明的句子。
- 数据体积：开源语录库较大，需本地筛选后内嵌，控制单文件体积。

## 十、已确认决策（用户最终答复）

1. 励志句子：使用鼓舞人心的中文励志格言（56 条公版名句/通用励志语），不自行生成、不显示来源。
2. 短休息：每轮之间插入短休息，休息时长可自行调整（默认 5 分钟）。
3. 目标日期模式：与番茄钟并存，可在设置页切换。
4. 界面简洁化：移除开源协议、语录来源等无意义小字；倒计时全程保持大号。
